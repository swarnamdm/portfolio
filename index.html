03 DEMO / CONCEPT PROJECT

Data Warehouse with Snowflake & dbt

A layered ELT design that keeps raw data replayable and moves tested business logic into version-controlled models.

SnowflakedbtSQLELT +
Land source records unchanged in Snowflake RAW.
Cast, rename, and filter in one dbt staging model per source.
Build business-ready revenue and customer marts through ref().
Test keys, accepted values, and relationships before BI consumption.

staging_orders.sql

with source as (
  select * from {{ source('raw', 'orders') }}
)
select order_id, customer_id,
  cast(order_ts as timestamp) as order_ts,
  cast(quantity as integer) as quantity
from source
where order_id is not null and quantity > 0

mart_revenue.sql

with orders as (
  select * from {{ ref('stg_orders') }}
)
select order_date, count(*) as order_count,
  round(sum(quantity * unit_price), 2) as gross_revenue
from orders
group by order_date
